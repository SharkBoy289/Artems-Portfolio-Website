## Why I built it

I use Angular at work, and I wanted a side project to try two newer parts of it:
standalone components and server side rendering. SSR changes how an app is
structured and shipped, so I wanted to see that firsthand.

## How it works

- **Standalone components.** The app uses the standalone model with no
  NgModules, with dedicated `login` and `register` components and typed routing.
- **Server side rendering.** It's set up with `@angular/ssr` and an Express
  server entry, so pages render on the server first.
- **TypeScript throughout,** with `RxJS` for async data.
- **Tests wired up** with Karma and Jasmine.

## Stack

Angular 18 (standalone components) · TypeScript · `@angular/ssr` + Express ·
RxJS · Karma / Jasmine.
