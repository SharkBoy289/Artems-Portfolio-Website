## The idea

My data is scattered across apps that don't talk to each other. MeOS is my
attempt to fix that for myself: a local first hub that pulls in data I own,
like contacts, calendar, notes, and my own platform exports, and shows it in one
place. An LLM helps summarize it and send things where they belong.

It's built as modules behind a shared shell, so it can grow over time. Tools
I've already built, like the job tracker, fit in as modules.

## The first module: a personal network graph

The first piece is an interactive, force directed graph of the people in my
life and how they connect. Each person is a node with notes on how I know them,
when we last talked, and what we have in common. You can drag, zoom, and explore
it in real time.

It only uses data I own: my own contacts and my own "download your data"
exports. It doesn't scrape anyone else's social data.

## What's interesting about it

- **A force directed graph in the browser** that stays smooth as the number of
  people grows.
- **An LLM that routes things.** A single capture box sends any note or link to
  the right module, using structured output calls.
- **Local first.** The data lives on my machine, so the system keeps working no
  matter what happens to any vendor.

## Where it is now

In progress. The network graph works and is the piece I demo. The data import
and the daily summary are still being built.
